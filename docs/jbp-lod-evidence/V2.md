## Runtime compiler and validation boundary

- `vk.shader.ShaderCompiler` invokes the game's LWJGL shaderc, targeting Vulkan 1.3 and SPIR-V 1.6. It resolves Voxy-style `#import <namespace:path>` recursively, rejects invalid imports/cycles, strips imported `#version` directives, and applies ordered macro definitions through shaderc.
- Successful shaderc output is checked for SPIR-V magic/header, instruction word lengths, memory model and entry point; LWJGL SPVC parses it and reflects descriptor set/binding, descriptor kind/name, stage input/output locations, and push-constant struct size. This implementation does not invoke a standalone `spirv-val` executable; no claim of an independently run spirv-val pass is made.
- Each `CompiledShader` returns the SPIR-V bytes, immutable-by-contract source/stage/define and SHA-256 trace (including imported source hashes), plus reflection. The exercised JUnit coverage test writes `build/reports/jbp-lod-spv-manifest.json` with those trace/reflection fields.
- `DeviceCaps.inspect(GameVulkan.Snapshot)` queries the borrowed game physical device and captures device/API/driver identifiers, queue-family indices, relevant format optimal-tiling features (including B8/R8 UNORM/SRGB, R16G16B16A16 SFLOAT and depth formats), storage/uniform/compute limits, push-constant size, max indirect draw count, subgroup properties, and support/enabled state for `drawIndirectFirstInstance`, `multiDrawIndirect`, `drawIndirectCount`, and `shaderInt64`. Core baseline requirements are Vulkan 1.3, game graphics and compute queue families, enabled `drawIndirectFirstInstance` (required for nonzero indirect `firstInstance`), storage range of at least 16 bytes, and a 256-invocation X workgroup; `requireCore()` reports every missing item and explicitly states there is no OpenGL fallback. No actual device snapshot values are recorded yet.

## Shader coverage inventory

The coverage test currently defines 29 compile cases for 15 shader entrypoints. `lod/` entrypoints are the upstream active LOD traversal, cleaner, mesh/indirect-command preparation, and draw/cull paths; `util/` entrypoints are direct helpers used by that path. Shared imported helpers are compiled through their consumers. The test cases use deterministic, compile-only external binding/size values; these are not a runtime binding allocation record.

| Entry point | Compile cases |
|---|---|
| `lod/hierarchical/traversal_dev.comp` | Base; `HAS_STATISTICS`; reverse-Z plus zero-to-one depth conversion. |
| `lod/hierarchical/cleaner/batch_visibility_set.comp` | Base explicit descriptor bindings and push-constant layout. |
| `lod/hierarchical/cleaner/result_transformer.comp` | Base explicit descriptor bindings and push-constant layout. |
| `lod/hierarchical/cleaner/sort_visibility.comp` | Base explicit descriptor bindings and sort parameters. |
| `lod/gl46/prep.comp` | Base. |
| `lod/gl46/cmdgen.comp` | Base; `HAS_STATISTICS`. |
| `lod/gl46/buildtranslucents.comp` | Base translucent-offset/write-base bindings. |
| `util/prefixsum/inital3.comp` | No-subgroup fallback (imports `simple.comp` under the fallback branch); subgroup path; `IS_INTEL` subgroup-index path; `IS_WINDOWS` shared-value workaround. |
| `util/prefixsum/simple.comp` | Direct fallback shader compile. |
| `util/memcpy.comp`, `util/scatter.comp` | One base compile each. |
| `lod/gl46/quads3.vert` | Default two-u32 quad representation; `USE_SHADER_INT64`; TAA patch helper injection. |

| `lod/gl46/cull/raster.vert` | Base; TAA helper injection. |
| `lod/gl46/cull/raster.frag` | Base. |

All ported shader resources carry an upstream source-path header, and `mods/jbp-lod/NOTICE` lists their MCRcortex/voxy 263 paths. Vulkan ports use descriptor set 0 and explicit bindings, Vulkan built-ins and push constants where applicable. The quad vertex shader's default `ivec2`/two-u32 storage path is the shaderInt64 fallback; `USE_SHADER_INT64` is only an optional alternate. The prefix-sum fallback is the no-`USE_SUBGROUP` shared-memory path. `drawIndirectCount` and `multiDrawIndirect` are command-path choices, not GLSL variants; `DeviceCaps` exposes support/enabled state. V4 owns the fixed-count `drawIndirectCount` and single-command `multiDrawIndirect` fallbacks; neither command fallback has been runtime-tested here.

`lod/gl46/quads.frag` does not sample the currently attached depth image: V4's CUTOUT hook occurs inside dynamic rendering, so depth testing is provided by fixed-function pipeline state. The vertex/fragment shaders use the V4-coordinated set 0 binding 8 fog std140 ABI (96 bytes: `mat4 modelView`, `vec4 fogColor`, `vec4 fogRange`); reflection exposes its declared block name `LodFogBlock` (instance `FogUniform`), and coverage asserts that block at binding 8. The vertex stage interpolates spherical view-space distance and the fragment stage applies Sodium fog color/range/alpha while preserving source alpha. This ABI and visual result still require game/GPU validation.
